# MuseScore Custom Build — Changelog

Custom features and notable fixes built on top of upstream MuseScore, since this branch diverged from `main` around 2026-08-25.

## Features

### 2026-10-22
- Audio sync: turning sync on for the first time puts a sync point on every measure start (repeats unrolled) and at the score's end, at their current time, ready to be dragged onto the audio's barlines.
- Audio sync Detect: a new beat tracker places the measures on the strong beats. The window asks for an approximate tempo (typed, or tapped with the Tap button or Space while the music plays, with Play/Pause right there), a Steady/Flexible tempo slider and whether to ignore the silence at the beginning; a measure gets a beat more or less only for a flexible tempo, and a score start placed by hand is kept.
- Audio sync window: dragging a point can move the following points too (a toggle button, or Cmd/Ctrl held for one move), shown moving during the drag; an east-west cursor over a point that can be dragged; the score's start point in green; double-click on the measures ruler plays from there, a point is added on the points row only; the A-B loop is dragged on the waveform only; Rewind and Go to loop start scroll the waveform there; loading another audio file starts over (undoable), a missing file located again keeps its sync points.

### 2026-10-21
- Audio sync: a new "Audio" menu (also in View) opens the Audio sync window, which syncs the score's playback to a reference recording (wav, mp3, flac, ogg…, dropped or loaded, with recent files). The audio is never stretched: the score's tempo follows it. Sync points placed on the audio's waveform (double-click adds or removes one, drag moves it, undoable) are tempo curve points, shown in the Tempo automation lane. With sync on, the score's tempo markings, fermatas and breaths are ignored for playback; off, the score's own tempo is back and the sync points are kept. Detect… finds the beats from the score's start and places a point per measure (points kept by the user are left as they are), uncertain ones shown hollow. With sync off, the reference (where the score starts in the audio) can be moved, all points with it.
- Audio sync window: measures ruler (numbers, beats, time signatures) above the waveform, time ruler below, overview of the whole audio, zoom and vertical zoom, stereo/mono view, its own transport (clock, metronome, Mute/Solo, go to start / to A, play, stop, A-B loop, follow playback), Pitch and Speed (the score's tempo multiplier, the audio following it without changing pitch) sliders, and a channel strip (Gain, EQ, Pan, fader, Mute/Solo). The reference audio is an "Audio" channel in the Mixer and the Track list, with its own Track delay. The window's view (zoom, scroll, amplitude) is saved in the score. New starts again: no audio, no sync points, pitch, speed and zoom reset.

### 2026-10-20
- Percussion panel: an "Edit pad" window edits one pad of the kit at a time, opened by a pad's right click "Edit pad…", an empty slot's (a new pad there), the panel's Edit pad button (the pad or empty slot clicked, else the selected note's pad) and Customize kit button, and the staff's right click "Customize kit…" (that staff's kit). It stays on top while MuseScore is active and is hidden when another app is. While it's open, clicking a pad or an empty slot edits it; Previous / Next pad go through the panel's order; Apply validates without closing, and going to another pad with changes not applied asks Cancel / Don't apply / Apply. New kit (removes all the pads, undoable), Load and Save as (.drm files, in Documents/MuseScoreStudio5/DrumKits, the library's name proposed).
- Drum pads: the note a pad plays is no longer its pitch in the score. It's chosen on a 128-key keyboard (with an overview of the whole keyboard), played when clicked, or learnt from the MIDI keyboard (which doesn't write in the score meanwhile); the score's notes never move. So several pads can play the same key in different articulations, e.g. a snare hit and a snare roll on C3 in a library's Hits and Rolls banks. Used by playback and MIDI export, saved with the score and in .drm files. A new pad given a note free in the kit also takes it as its pitch in the score, so it gets back the notes already written for it (e.g. after New kit).
- Drum pads: a pad can be linked to an articulation of the instrument's articulation map (e.g. Rolls): its notes always play in it, whatever the score says, and clicking it in the panel or on the keyboard sends its keyswitch first. The keyboard shows the pad's note, the other pads of its articulation (its bank) and, in red, the key triggering it when it's a keyswitch; hovering a key tells what plays it. Buttons open the articulation map editor and the VST instrument's window.
- Drum pads: the appearance as in Customize kit (notehead group, custom noteheads with their glyphs, staff line, voice, stem, shortcut), with a preview on the staff's real number of lines. A warning only when another pad plays the same note in the same articulation.
- Percussion panel: no Write / Preview buttons: a pad writes its note only during note input (whatever the input method), else it's only heard - the panel never starts note input. Edit pad, Layout and Customize kit buttons in the middle (Layout stays during Edit layout, next to Finish editing); a clicked pad or empty slot is outlined; pads show the note they play, named as in the articulation map (C3 or C4 for middle C).
- Customize kit: back to MuseScore's own window (the 2026-10-16 changes are undone); the new Edit pad window replaces it in the menus.

### 2026-10-18
- Export > MP4 video (score): about half the size at the same picture quality (e.g. 34 → 16 MB for a 2 min 15 s 1080p video) — a full picture every 5 s instead of every 0.5 s, a score's pictures hardly changing in between.
- Track list: a button at the right of the header shows/hides the channel strip, in sync with the "…" menu's Channel strip item. The button stays left of where the scroll bar appears, so its clicks don't go to the scroll bar.
- Export > MP4 video (score): "Add score title at the beginning" and "Add MuseScore logo at the end" checkboxes (both on by default, remembered) to keep or leave out the black title screen and the "Made with MuseScore Studio" screen; the audio follows. Without the title, the video starts on the score's first page, held silent for 1 s before the music, so the first notes don't start the instant the video plays. Sample rate, bit rate and video resolution are now on one row (the last checkbox went under the Cancel button).

### 2026-10-17
- Playback toolbar: the Play button has a dropdown arrow to choose what a stop does to the playback position: "Stay at stop position" (MuseScore's usual behavior, the default) or "Return to start position on stop" — when playback stops (Space, Pause, Stop or the end of the score), the playback position goes back to where playback started. Remembered between sessions; the button's tooltip shows the mode (e.g. "Play – Return to start position on stop"); both modes are also actions that can get shortcuts.
- Score context menu: on a VST instrument staff, a row of icons at the top - note velocities, note offsets, articulations, CC01, CC11, last MIDI CC used, articulation map editor and the VST instrument's window - the same buttons as the circular toolbar, for the clicked instrument (keyboard: Left/Right along the row). They only turn on an editing mode, so the selection made by the right-click (e.g. a measure in an empty part of the staff) goes back to the previous one. The last MIDI CC is shared with the circular toolbar.
- MIDI CC recording: while Record MIDI CC is on, the recorded staff follows the selection (no need to turn the button off and on again to record another staff); it stays the same during a take, and a selection that isn't a VST instrument staff keeps the previous one.
- Circular toolbar: the Tempo button shows "♩ =", like a tempo mark, to tell it at a glance.
- Mixer: a Track delay section for VST3 tracks (under Sound, hidden by default: "…" > View > Track delay): a knob and its field, -500 to +500 ms, shift everything the track plays - notes, articulation triggers, CCs, dynamics, pedals and pitch bends (e.g. a library whose attacks are late); applied when the knob is released or the value typed, undoable, saved with the project and in track presets. An articulation's Note delay now also takes the notes' pedals and pitch bends along.

### 2026-10-16
- Articulation map editor: "Activation sequence" is now "Trigger" (keyswitches, CCs or program changes); "Track delay", which only sets when the triggers are sent (never the notes), is now "Default trigger delay", and an articulation's "Articulation delay" is now "Trigger delay", next to "Note delay" (which shifts its notes, e.g. a late legato). The map files don't change.
- Track list: a folder's Mute/Solo button is on as soon as one of its tracks is muted/soloed, and a click then unmutes/unsolos them all (e.g. one click ends the solos of 4 string tracks); off, a click mutes/solos them all. Nothing is remembered; the global Mute/Solo buttons still restore what they turned off.
- macOS: a VST3 plugin's window (and an extension's) no longer disappears when another app becomes active: it stays shown, behind that app's windows, and comes back above the score when MuseScore is active again. It's hidden while MuseScore's window is minimized and comes back with it (Windows already behaved this way).
- Articulation lane: a mark's menu has "All following notes" (next to "This note only"): the following notes play the mark's articulation even when they carry a staccato dot, an accent…, until the next mark — e.g. a staccato passage played spiccato from one mark. A playing technique written after it ("pizz."…) takes over; the mark's chip is outlined.
- Customize kit (percussion staves): the window no longer blocks MuseScore. It stays on top by default (Always on top checkbox, like the articulation map editor) and its title names the instrument; the kit changed meanwhile by undo/redo or the Percussion panel shows in it. Cancel, the close button and Escape revert only what the window changed since it was opened or applied (Apply now validates); closing the score reverts nothing.
- Track list: the Metronome row's color can be changed (Edit color… / Reset color on its color strip, undoable), and the Mixer shows it in the Metronome's title.
- Mixer (normal and condensed views) and Track list: a channel's left and right meters have the same width at any panel zoom (at 90 % the right one looked narrower); the meters no longer redraw a canvas at every level change.
- Mixer and Track list channel strip: a channel's Aux send slots can be reordered by dragging their bus button, like the Audio FX slots. Only how they're shown (the sends are parallel, the sound doesn't change): the same order in both panels, saved with the project, undoable; empty slots stay last.
- Project loading window: once a project opened from the Home page is loaded, Space starts playback again instead of switching back to the Home tab (the window gave the keyboard back to the Home tab when it closed).
- Track list: a row's right click menu has the Mixer's Add FX channel / Add Group channel (and, on a track, the same "for selected tracks"), Delete channel on an FX or Group bus (not the Reverb one), then the track presets items last. Bus rows show the Mixer's FX / GRP label between Solo and the meter. Adding or deleting a bus can be undone whichever of the Mixer and the Track list is open, and opening a project no longer leaves an undo step per bus (an undo right after opening could delete one).
- Articulation maps: the changed map files found when a score opens are listed in a fixed-size window with a scrolling list, each with a checkbox (all checked) and the parts using it; only the checked ones are reloaded, the others keep the versions saved with the score.
- Track list: folders of tracks and buses (e.g. Woodwinds, Brass, FX), only the Track list's organization: the score's order isn't changed and a folder's tracks are in it. Created from the header's folder button (above the selected track, or first) or a row's menu (Add new folder; Move to folder > New folder takes the track or the selection), renamed by double click, collapsed, removed (its tracks stay), filled and moved by drag and drop or the row's "Move to folder" menu. Kept in the project; every change but collapsing is undoable. A folder's Mute/Solo is on as soon as one of its tracks is muted/soloed: a click then unmutes/unsolos them all, else mutes/solos them all (an FX bus has no Solo).
- Track list: the list keeps its scroll position when rebuilt, and scrolls to a track selected in the score only when it's out of view; the channel strip area is always there (the selected channel, else the one shown last or the first track, its name bar dimmed when not selected); the articulation map and plugin buttons close their open window; View menu with Metronome first, as in the list; larger color strips and meters.

- Track list: a channel strip below the list shows the first selected track or bus with the Mixer's controls, in two columns: Gain, Pan, volume field, fader with meters, Mute/Solo; then EQ, the 5 Audio FX slots and the 5 Aux sends. Its name bar has the track's color; its height is dragged (up to all of it, remembered) and "..." > Channel strip shows or hides it. - Track list: no eye button any more (a hidden part stays dimmed; Load video moved to the sound column), 256 px wide when alone in its column, and the rows selected stay selected when the list is rebuilt (e.g. a kind of channels shown or hidden).
